# Background

Over the years, tech companies have worked hard to remove ownership from the end user by shifting to more profitable subscription based models. As part of my journey of taking back control, I decided to build a home server and begin self-hosting any service I can. Luckily I had a Dell Optiplex with 1Tb of HDD storage as is. I recently got a matching hard drive to set up a mirrored storage pool. As the project currently stands, I have a simple network attached storage but I plan to build further capabilities into the project including:

- A full replacement for Onedrive/Google Drive
- Photo management system to replace Google Photos
- A self hosted website (this one)
- An accessible media library
- A minecraft library

# What I've Learned

The biggest lesson I've taken away from the this project is that there is almost always open source options for the software we rely on every day. Returning power to the user is possible and important. I have also learned some basic PC building, IT, and networking skills.
